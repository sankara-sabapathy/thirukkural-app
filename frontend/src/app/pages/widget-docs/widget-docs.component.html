Customization

You can control theme, accent color, and a fixed Kural for editorial placements or previews.

{{ customSnippet }}
data-theme`light` or `dark`
data-accenthex color such as `#0f766e`
data-kuraloptional fixed Kural number from `1` to `1330`
data-widthoptional inline width, for example `360px`
data-max-widthoptional maximum width, default `420px`

Implementation Notes

  • The widget is rendered inside a hosted iframe, so it stays visually stable on third-party sites.
  • It links back to the full Kural page on `thirukkural.site` with attribution.
  • The default widget rotates daily using a UTC-based schedule.
  • For editorial placements, you can pin a specific Kural with `data-kural`.
